# 🔍 Basic Port Scanner

A lightweight and fast TCP port scanner written in Python. It allows users to scan a specified IP address across a range of ports using multithreading for improved speed.


## 🚀 Features

- Simple command-line interface
- Validates IP address input
- Scans ports using TCP connect
- Multithreaded scanning with `ThreadPoolExecutor` for faster results
- Displays all open ports within the specified range


## 📌 Requirements

- Python 3.x  
- No external libraries required (uses built-in modules)


## 🛠️ Usage

```bash
python Basic_Port_Scanner.py
